Создайте идентичность Nostr, защитите её ключом доступа вашего устройства и подготовьте восстановление до завершения настройки.

Руководство описывает работу с ключами доступа. Если этих элементов нет, проверьте установленную версию. Названия кнопок соответствуют английскому интерфейсу.

## Перед началом

Нужна версия с Create with passkey. Браузер и провайдер должны поддерживать PRF.

Начните с новой установки и подготовьте безопасное место для зашифрованного файла, доступное с другого устройства.

## Шаги

1. Выберите Create with passkey. В окне браузера для passkeys.nostrwot.com выберите провайдера и подтвердите.
2. Настройте восстановление. Если провайдер подтвердил сохранение данных, файл необязателен. Иначе выберите Download recovery file, сохраните файл и подтвердите, что ключ доступа тоже потребуется. Сохранение на реле не заменяет этот шаг.
3. При желании сохраните данные на реле и проверьте подтверждения. Оставьте файл как дополнительный способ восстановления.
4. Перейдите к настройкам защиты. Confirm сохраняет разблокировку ключом доступа и автоблокировку через 15 минут. Завершите настройку и запишите публичный npub.

## Проверка восстановления

Для зашифрованного файла нужен зарегистрированный ключ доступа, способный расшифровать эту копию. Одного файла недостаточно.

Обновляйте копию после изменения аккаунтов или ключей. Архивы событий сохраняются отдельно; подтверждение провайдера не доказывает синхронизацию с другим устройством.
