Создайте идентичность Nostr, защитите её ключом доступа вашего устройства и подготовьте восстановление до завершения настройки.

Руководство описывает работу с ключами доступа. Если этих элементов нет, проверьте установленную версию. Названия кнопок соответствуют английскому интерфейсу.

## Перед началом

Нужна версия с Create with passkey. Браузер и провайдер должны поддерживать PRF.

Начните с новой установки и подготовьте безопасное место для зашифрованного файла, доступное с другого устройства.

## Шаги

1. Выберите Create with passkey. В окне браузера для passkeys.nostrwot.com выберите провайдера и подтвердите.
2. Если провайдер поддерживает хранение данных восстановления, расширение сохраняет их автоматически. Подтвердите дополнительную аутентификацию. После подтверждения записи настройка переходит прямо к Protect your keys, без экрана скачивания и дополнительного нажатия Continue.
3. Только если хранилище провайдера недоступно или запись не удалась: выберите Download recovery file, сохраните файл и подтвердите, что ключ доступа тоже нужен. На этом резервном экране можно сохранить данные на реле; это не заменяет обязательные файл и подтверждение.
4. На экране Protect your keys кнопка Confirm сохраняет Use passkey и автоблокировку через 15 минут. Выберите подписки или пропустите этот шаг, затем завершите настройку на All Set. Запишите публичный npub для проверки при восстановлении.

## Проверка восстановления

Для зашифрованного файла нужен зарегистрированный ключ доступа, способный расшифровать эту копию. Одного файла недостаточно.

Дополнительный файл можно получить позже в Settings → Security → Passkey. Обновляйте копии после изменений аккаунтов или ключей. Архивы событий отдельные; подтверждённая запись не доказывает синхронизацию с другим устройством.
