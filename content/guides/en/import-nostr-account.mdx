Choose **Import Key or Backup** to bring an existing identity into this browser. You need its private key, recovery phrase or a supported encrypted backup. An npub is a public key and belongs in [Watch-Only](/guides/watch-only-nostr-account).

## Restore your existing identity

1. Open the extension popup and choose **Import Key or Backup** from the setup methods.
2. Paste your **nsec**, hex private key, or recovery phrase into the import field, or load your supported backup file. The extension detects the format.
3. For an **ncryptsec** or encrypted backup, enter the password used to encrypt it. This is the backup's password, not necessarily your browser vault password.
4. Continue after the format is recognized. If the extension reports an error, check the input and password before trying again. Keep the original backup intact.
5. Keep your existing recovery backup safe. Set the local vault password when prompted. If this browser already has a vault, unlock it with its existing password when asked.
6. Finish setup and compare the displayed public key with the npub of the identity you intended to restore.

## Recovery phrases and encrypted files

Existing 12-word and 24-word recovery phrases can be imported. A new identity generated by the extension uses 24 words. If your identity used a custom derivation path, keep that path and expected public key with your recovery records; see [custom identity paths](/guides/custom-identity-paths).

Importing a phrase starts with its first Nostr key; it does not automatically restore every sub-account or custom path. Read the import screen's seed notice: when the unlocked vault already has a main recovery phrase, only the first key from the additional phrase is imported, rather than storing it as another main seed.

An encrypted file's password protects that file. Setting a new local vault password does not change the password of an existing backup.

<Callout type="warning">
Enter private keys and recovery words only in the extension's import interface. Never send them to someone offering to help restore an account.
</Callout>
