L’extension Nostr WoT se connecte à un portefeuille Lightning pour consulter votre solde, recevoir des sats et approuver des paiements depuis le navigateur. Ouvrez l’extension, accédez à **Portefeuille**, puis choisissez **Configuration rapide**, **NWC** ou **LNbits**.

Si vous utilisez déjà Alby Hub, ses connexions d’applications facilitent le démarrage. Pour un portefeuille LNbits existant, l’API directe demande moins de configuration ; NWC propose des autorisations et budgets par connexion. La garde des fonds dépend du portefeuille et de son opérateur, pas du mode de connexion.

Retrouvez les étapes détaillées dans notre [guide Alby Hub](/guides/alby-hub-nwc) ou notre [guide LNbits](/guides/lnbits-wallet-setup).

## Configuration rapide

Choisissez **Configuration rapide** pour créer un portefeuille auprès du fournisseur configuré. Une fois la création terminée, utilisez **Déposer** pour générer une facture Lightning. Le fournisseur garde les fonds. NWC et LNbits ne garantissent pas non plus, à eux seuls, que vous détenez vos propres clés.

## Alby Hub avec NWC

Vous devez disposer d’un Alby Hub opérationnel et de son portefeuille Lightning.

1. Dans Alby Hub, ouvrez **Connections → Add Connection**.
2. Créez une connexion dédiée appelée **Nostr WoT**. Définissez les autorisations, le budget de dépenses et, éventuellement, une date d’expiration.
3. Autorisez les informations du portefeuille (`get_info`) pour valider la connexion. Ajoutez selon vos besoins le solde, les paiements, la création et la consultation de factures, ainsi que l’historique.
4. Copiez le secret de connexion complet, qui commence par `nostr+walletconnect://`.
5. Dans l’extension, choisissez **NWC**, collez le secret et cliquez sur **Connecter**.

Gardez ce secret confidentiel : il peut autoriser des dépenses. Vous pouvez modifier ou révoquer la connexion dans Alby Hub. Consultez le [guide officiel](https://guides.getalby.com/user-guide/alby-hub/app-connections).

## LNbits avec NWC

1. Demandez à l’administrateur de l’instance d’installer **NWC Service Provider** et de configurer un relais dans `/nwcprovider/admin`.
2. Ouvrez cette extension dans LNbits, sélectionnez votre portefeuille et ajoutez une connexion avec **+**.
3. Activez les informations du portefeuille et les opérations nécessaires. Définissez budget et expiration lorsque ces options sont proposées.
4. Créez la connexion et copiez son URL d’appairage.
5. Collez-la dans l’onglet **NWC** de Nostr WoT et connectez le portefeuille.

Se connecter à son compte LNbits ne crée pas une connexion NWC. Le [guide officiel du fournisseur](https://docs.lnbits.com/extensions/nwcprovider/) décrit la configuration du relais et le formulaire de connexion.

<a id="lnbits-api" className="block scroll-mt-32" />

## LNbits avec son API

1. Ouvrez le portefeuille concerné dans LNbits et recherchez **API info** ou son panneau de documentation API.
2. Copiez la **Admin API key** de ce portefeuille.
3. Dans l’onglet **LNbits** de l’extension, saisissez l’URL HTTPS de l’instance et cette clé, puis connectez-vous.

La clé Admin API est un identifiant du portefeuille, **pas votre mot de passe de connexion administrateur**. Elle permet les paiements sortants. La clé de facturation ou de lecture ne permet pas de dépenser et ne remplace pas la clé requise pour toutes les fonctions. Consultez [l’emplacement des clés LNbits](https://docs.lnbits.com/api/authentication#finding-your-keys). Une URL d’appairage NWC appartient à l’onglet **NWC**, pas au champ de clé API.

## Autres portefeuilles et vérifications

Dans YakiHonne, copiez ou exportez un secret NWC si votre portefeuille propose cette option. Les autres fournisseurs NWC suivent le même parcours ; les fonctions disponibles dépendent de leur implémentation et des autorisations.

Le plugin Nostr habituel de BTCPay Server se connecte **à** un portefeuille NWC externe. Il ne fournit pas lui-même de secret pour cette extension. Créez une connexion distincte dans le portefeuille utilisé ou son pont NWC ; voir les [options Lightning de BTCPay](https://docs.btcpayserver.org/LightningNetwork/).

Après connexion, vérifiez solde et historique. En cas de problème, contrôlez autorisations, expiration et disponibilité du portefeuille. Si l’issue d’un paiement est inconnue, consultez l’historique avant de réessayer. Pour changer de portefeuille, déconnectez-le dans ses paramètres.

Poursuivez avec les [zaps et l’approbation automatique](/guides/zaps-et-approbation-automatique) ou les [adresses Lightning](/guides/adresse-lightning).
