## Выпущенное улучшение поиска ответов

[Amethyst 1.15.2](https://github.com/vitorpamplona/amethyst/releases/tag/v1.15.2), опубликованный 12 сентября в 14:42 UTC, доступен для загрузки на Android и настольные системы. [Изменение фильтров NIP-22](https://github.com/vitorpamplona/amethyst/pull/4095) позволяет находить вложенные комментарии по корню обсуждения наряду с существующими запросами прямых ответов.

Разница невелика, но важна: ответ на комментарий указывает исходное обсуждение в теге с заглавной буквой, а тег со строчной буквой указывает непосредственного родителя. Поиск только по родителю пропускает такой вложенный ответ при запросе исходной записи. Отдельные фильтры корня исправляют запрос. Доступность ретрансляторов и временные ограничения по-прежнему определяют, какие события придут; изменение не гарантирует загрузку всех ответов.

В той же версии исправлен поиск обновлений запросов на слияние NIP-34. Наш [разбор исходного кода](https://nostr-wot.com/news/nip-22-amethyst-loads-nested-comments) объясняет оба случая. Файлы на GitHub подтверждают распространение через этот канал, но не статус публикации в магазинах приложений.

## Расширение и SDK на момент закрытия выпуска

Этот восстановленный выпуск охватывает период с 11 сентября, 08:00 UTC, до 18 сентября, 08:00 UTC. [Версия расширения 0.7.0](https://github.com/nostr-wot/nostr-wot-extension/releases/tag/v0.7.0), опубликованная 10 сентября в 22:29 UTC, остаётся исходной версией GitHub на конец периода. Это контекст предыдущего выпуска. Её [опубликованный журнал изменений](https://github.com/nostr-wot/nostr-wot-extension/blob/v0.7.0/CHANGELOG.md) описывает пути идентичностей и восстановление; доступный ZIP для Firefox не подтверждает наличие в магазине Firefox.

Официальные данные npm по всем 12 публичным пакетам SDK не показывают новых версий за этот период. Версия [основного пакета](https://registry.npmjs.org/nostr-wot-sdk) на конец периода: 1.0.1, опубликованная 16 августа. Релизы от 19 и 20 сентября относятся к следующему выпуску и здесь исключены.

## Полезная проверка для разработчиков клиентов

Если вложенный ответ появляется только после открытия ветки, сравните фильтры непосредственного родителя и корня, прежде чем предполагать отсутствие контента. Патч Amethyst даёт конкретную реализацию для изучения. Используйте одноразовые тестовые события и проверяйте фактический запрос к ретранслятору: тег протокола и его обработка клиентом являются разными вещами.
